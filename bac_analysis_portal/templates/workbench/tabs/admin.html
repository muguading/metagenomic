脚本路径设置

先选择 Conda 安装路径，系统会扫描该目录下的 base 与 envs 环境；运行时使用当前 Conda 安装路径下的 conda 执行 conda run -n 环境名 --no-capture-output python -u 主脚本。数据库部署目录用于参考数据库、病毒分型数据库等统一定位。

Conda 运行环境映射
